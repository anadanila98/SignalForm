# Angular 22 Signal Forms Demo

A small demonstration project showcasing the new **Signal Forms** feature introduced in **Angular 21**.

## Overview

This project provides a simple, focused example of how to build and manage forms using Angular's Signal Forms API. It is intended as a lightweight reference for developers who want to explore the new reactive form patterns powered by signals.

## Features

* Basic Signal Forms setup
* Form state management using signals
* Validation examples
* Clean and minimal implementation for easy understanding

## Purpose

The goal of this project is to demonstrate the fundamentals of Signal Forms without unnecessary complexity, making it a good starting point for learning and experimentation.

## Requirements

* Angular 22
* Node.js (latest LTS recommended)

## Getting Started

```bash
npm install
ng serve
```

Then open `http://localhost:4200` in your browser.

## Notes

This project is intended for educational purposes and focuses on demonstrating the Signal Forms API rather than providing a production-ready application.
